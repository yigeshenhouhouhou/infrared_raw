红外 RAW 后端与本地调色界面

新版色彩 / 测光
  默认“590 nm 蓝金”方案包含线性光混色、色彩分离和蓝黄定向调整。
  可调色彩分离、暖色金黄、蓝色校正、自然饱和；经典原始通道方案仍保留。
  新方案已经混色，通常不要叠加附加红蓝互换。中性白平衡仍应先用吸管校准。
  创意假色没有识别天空 / 植被 / 墙壁的语义能力，相近通道比例的物体会一起变化。
  自动曝光更多参考主体有效亮度，不再只被最亮通道支配；手动 EV 与高光仍可调整。
  细节见 android\RELEASE-0.2.1.txt。

启动
  双击“启动红外白平衡.bat”。环境已装在本目录 .venv。
  界面只监听 127.0.0.1；照片在本机处理，不上传云端。
  若搬动项目位置导致环境失效，在 E 盘新位置运行“安装环境.bat”。

建议操作
  1. 拖入 RAW。整幅平均白平衡只是起点，用吸管框选中性区域更可靠。
  2. 先用“中间调”提亮主体，再微调曝光。曝光可调 -8 至 +8 EV。
  3. “高光”越高，高光压缩越强。曝光、对比度之后才压缩高光。
  4. R/B 支持数值输入 0.0001–10000，不受 Lightroom 色温限制；G 固定为 1。
     快速滑块范围为 0.001–64，范围外请直接输入数值。
     改白平衡会改变通道亮度，必要时点“自动曝光”重算曝光起点。
  5. 界面显示各 CFA 通道的传感器饱和比例。这与显示白色不是同一回事。
  6. 各张照片保留本次会话的独立调整，批量导出使用各自参数。

导出
  “导出 JPG”按钮：直接将当前照片的全部调色效果导出为原图尺寸 JPG，
    质量 95、4:4:4 色度采样、内嵌 sRGB ICC；保存到 output，同时保存参数 JSON。
    格式选择框也可选择 JPG，配合“全部导出”批量保存各张照片。
  保留原 demo 新增的“黑场”调整：默认 0，不影响现有调色；值越大暗部越深。
  16-bit 成片 TIFF：显示用 sRGB 假色，含 ICC，包含所有调色效果。
  32-bit 浮点底片 TIFF：线性相机 RGB，包含白平衡、自动曝光基准及曝光 EV，
    保留超过 1 的数据；不包含高光曲线、中间调、通道互换、降噪等成片效果，
    不嵌入 sRGB ICC。需要理解线性相机 RGB 的 HDR/科学软件读取。
    这不是 DNG，也不是能在 Lightroom 中继续按原始 RAW 调整的文件。
  每个 TIFF 旁保存同名 .json 参数记录。重名导出生成新文件，不覆盖原片。
  默认输出 output，上传的 RAW 会话副本在 output\.cache。
  正常退出服务会删除本会话上传副本；异常退出残留可在服务关闭后手工清理。
  环境、临时目录 runtime\tmp 和依赖缓存都在本项目的 E 盘目录中。
  原 C 盘 demo 保留，未修改；请使用 E 盘的新启动文件。

核心变化和边界
  LibRaw 仅去马赛克并减黑电平，关闭自动缩放、自动提亮、可见光色彩转换及 WB。
  按传感器白电平归一化后，在 float32 中进行白平衡与曝光，避免 LibRaw 的
  16-bit 成片通道因大白平衡倍率提前裁剪。原始 12/14/16-bit 有效精度不凭空增加。
  相机改机后，可见光相机矩阵不再是准确的红外色彩标定。因此本版明确采用
  相机通道假色，在最终显示时分配为 sRGB；颜色与旧 demo 可能不同。
  高光采用共用 RGB 增益的对数肩部曲线，保留通道比例；使用标准 sRGB 传递函数。
  真实传感器饱和处不做虚构细节的“恢复”；有通道已饱和时仍可能出现偏色。
  高光曲线处理的是现有 RAW 信息。极端 EV 最终 16-bit 成片仍有量化限制。
  预览缓存小图，调整 WB 不再重复去马赛克；最多缓存两张相机通道预览。
  预览与全尺寸导出共用相同曝光、高光、调色公式，但去马赛克分辨率不同，
  细节、降噪及锐化可能略有差别。本版没有空间局部色调映射或复杂 AI 降噪。
  支持 LibRaw 可解码的三色 RGB RAW，特殊四色传感器会明确报错。
  所有调整与图像预览是本会话状态；重启服务需重新导入，未实现自动恢复工程。

验证
  .venv\Scripts\python.exe -B test_process.py
  .venv\Scripts\python.exe -B test_ir_wb.py
  回归覆盖真实 LibRaw 合成 DNG 解码、超白数据、极端曝光/对比度高光梯度、
  黑电平与逐通道白电平、ICC/浮点导出、预览/全尺寸一致性及上传/导出 HTTP 流程。

命令行示例（所有输出请写 E 盘）
  .venv\Scripts\python.exe -B ir_wb.py info "E:\照片\sample.ARW"
  .venv\Scripts\python.exe -B ir_wb.py solve "E:\照片\sample.ARW" --region 0.2,0.3,0.5,0.6
  .venv\Scripts\python.exe -B ir_wb.py apply "E:\照片\sample.ARW" --mul 0.4,1,2.3 --out "E:\照片\result.tif"
  .venv\Scripts\python.exe -B ir_wb.py apply "E:\照片\sample.ARW" --mul 0.4,1,2.3 --linear --out "E:\照片\linear.tif"
